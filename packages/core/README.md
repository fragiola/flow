# @fragiola/flow

The framework-free core of **Flow**, headless node-based editors and diagrams: the flow document
with its JSON Schema, a typed model whose every change is a command (`run`, `can`, `check`, `get`,
`is`), opt-in features and the engine that binds a flow to the DOM (viewport, measurement, handles,
edge paths, gestures). Zero runtime dependencies, no CSS.

Not usable yet: version `0.0.0` is the repository's foundation, and nothing is published.

Documentation: **<https://fragiola.com/flow>** (coming soon). ESM only.
