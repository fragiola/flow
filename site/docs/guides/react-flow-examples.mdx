React Flow ([xyflow](https://github.com/xyflow/xyflow)) has a catalogue of examples, and a team
moving from it looks for the same cases here. This page maps the examples its examples page listed
in November 2026, the ones in the table below, to the gallery example that shows each; an example
React Flow added later is not here until this page is updated. Some cases share an example, because one flow shows them together. A few are not an
example: the five themes every example runs in cover them. Every example is our own code, data and
look: React Flow was a reference for the behaviour only, and nothing was copied from it.

The newest examples are written in React first, and Vue, Svelte and Angular follow. What the package leaves to the app (layout, undo, copy and
paste, helper lines) is code in the example that you copy: see
[What it never ships](/docs/getting-started/introduction#what-it-never-ships).

## What the examples bring

Only the layout examples use a library of their own: `@dagrejs/dagre`, `elkjs` and `d3-force`,
which you install with the example's code (its code panel lists them). The rest is
built in the example from the package's API: the collaborative one syncs over a
`BroadcastChannel`, the image export draws its SVG from the flow's geometry and turns it into a PNG
on a canvas, and the whiteboard smooths its strokes itself.

Every layout example moves the nodes the same way, whatever computes the positions: an animation
is one `node.move` batch per frame run as a transient step, then one final batch the history keeps
(see [Transient steps and batches](/docs/concepts/model-and-commands#transient-steps-and-batches)).
