---
title: Minimap and controls
description: Add zoom, fit and lock buttons that know when they are disabled, and a minimap that shows the whole flow and pans it when dragged.
---

`Flow.Controls` groups the viewport's buttons: `Flow.ZoomIn`, `Flow.ZoomOut`, `Flow.FitView` and
`Flow.ToggleInteractive`. Each runs one engine action and is disabled while the engine would refuse
it. `MiniMap` (from `minimap()`) draws every node small, with a mask over what the root does not
show, and pans and zooms the flow from there. Both render no icon and no text: the icons, the
names, where they sit and how they look are yours.

<Example id="minimap-and-controls" />

## The control buttons

Put `Flow.Controls` inside `Flow.Root`, outside `Flow.Viewport` (it must not pan or zoom), and place
it with your style. Presses and the wheel over it are left to it.

<Framework name="react">

```tsx
import { Flow } from "@fragiola/flow-react";
import { LockIcon, MaximizeIcon, MinusIcon, PlusIcon, UnlockIcon } from "lucide-react";

<Flow.Controls role="group" aria-label="Zoom and lock" className="absolute bottom-3 start-3 flex flex-col">
    <Flow.ZoomIn aria-label="Zoom in" className="control">
        <PlusIcon />
    </Flow.ZoomIn>
    <Flow.ZoomOut aria-label="Zoom out" className="control">
        <MinusIcon />
    </Flow.ZoomOut>
    <Flow.FitView aria-label="Fit view" className="control">
        <MaximizeIcon />
    </Flow.FitView>
    <Flow.ToggleInteractive
        aria-label="Lock the flow"
        className="control"
        render={(props, state) => (
            <button {...props}>{state.interactive ? <UnlockIcon /> : <LockIcon />}</button>
        )}
    />
</Flow.Controls>;
```

</Framework>

<Framework name="vue">

```vue
<script setup lang="ts">
import { Flow } from "@fragiola/flow-vue";
import { LockIcon, MaximizeIcon, MinusIcon, PlusIcon, UnlockIcon } from "@lucide/vue";
</script>

<template>
    <Flow.Controls role="group" aria-label="Zoom and lock" class="absolute bottom-3 start-3 flex flex-col">
        <Flow.ZoomIn aria-label="Zoom in" class="control">
            <PlusIcon />
        </Flow.ZoomIn>
        <Flow.ZoomOut aria-label="Zoom out" class="control">
            <MinusIcon />
        </Flow.ZoomOut>
        <Flow.FitView aria-label="Fit view" class="control">
            <MaximizeIcon />
        </Flow.FitView>
        <Flow.ToggleInteractive v-slot="{ state }" aria-label="Lock the flow" class="control">
            <UnlockIcon v-if="state.interactive" />
            <LockIcon v-else />
        </Flow.ToggleInteractive>
    </Flow.Controls>
</template>
```

In Vue, a button's default slot gets its state (`v-slot="{ state }"`): no `render` needed to
swap the icon.

</Framework>

<Framework name="svelte">

```svelte
<script lang="ts">
    import { Flow } from "@fragiola/flow-svelte";
    import { LockIcon, MaximizeIcon, MinusIcon, PlusIcon, UnlockIcon } from "@lucide/svelte";
</script>

<Flow.Controls role="group" aria-label="Zoom and lock" class="absolute bottom-3 start-3 flex flex-col">
    <Flow.ZoomIn aria-label="Zoom in" class="control">
        <PlusIcon />
    </Flow.ZoomIn>
    <Flow.ZoomOut aria-label="Zoom out" class="control">
        <MinusIcon />
    </Flow.ZoomOut>
    <Flow.FitView aria-label="Fit view" class="control">
        <MaximizeIcon />
    </Flow.FitView>
    <Flow.ToggleInteractive aria-label="Lock the flow" class="control">
        {#snippet children({ state })}
            {#if state.interactive}<UnlockIcon />{:else}<LockIcon />{/if}
        {/snippet}
    </Flow.ToggleInteractive>
</Flow.Controls>
```

In Svelte, a button's `children` snippet gets its state (`{#snippet children({ state })}`): no
`render` needed to swap the icon.

</Framework>

<Framework name="angular">

```html
<!-- the component imports FLOW and LucidePlus, LucideMinus, LucideMaximize, LucideLock, LucideLockOpen (@lucide/angular) -->
<div flowControls role="group" aria-label="Zoom and lock" class="absolute bottom-3 start-3 flex flex-col">
    <button flowZoomIn aria-label="Zoom in" class="control"><svg lucidePlus aria-hidden="true"></svg></button>
    <button flowZoomOut aria-label="Zoom out" class="control"><svg lucideMinus aria-hidden="true"></svg></button>
    <button flowFitView aria-label="Fit view" class="control"><svg lucideMaximize aria-hidden="true"></svg></button>
    <button flowToggleInteractive #lock="flowToggleInteractive" aria-label="Lock the flow" class="control">
        @if (lock.state().interactive) {
            <svg lucideLockOpen aria-hidden="true"></svg>
        } @else {
            <svg lucideLock aria-hidden="true"></svg>
        }
    </button>
</div>
```

In Angular, the buttons are yours (`<button flowZoomIn>`) and a button's state is its `state()`
signal through its `exportAs` (`#lock="flowToggleInteractive"`): no `render` needed to swap the
icon.

</Framework>

| button | runs | disabled while |
| --- | --- | --- |
| `Flow.ZoomIn` | `zoom-in` (a step of `zoomStep`, default 1.2, around the root's centre) | at `maxZoom` |
| `Flow.ZoomOut` | `zoom-out` | at `minZoom` |
| `Flow.FitView` | `fit-view` (every node in view) | before a node is measured |
| `Flow.ToggleInteractive` | `set-interactive` | only before the root is mounted (no engine yet); `aria-pressed` while the flow is locked |

A disabled button has `disabled` and `data-disabled`: style it with `disabled:opacity-40`. The
lock turns dragging, connecting and selecting off (`set-interactive { drag, connect, select }`,
React Flow's interactive button): no drag, no connection, no selection, nor their keys; panning
and zooming stay, and the toggle loses `data-interactive` (the root keeps it: the flow is still
`interactive`, which the root's `interactive={false}` turns off whole). Each kind is also its own
switch from code:

```ts
engine.run("set-interactive", { connect: false }); // no new edges; drag and select stay
engine.is("interactive-by", { kind: "connect" }); // false
```

## Animated buttons

`duration`, in milliseconds, on `Flow.ZoomIn`, `Flow.ZoomOut` or `Flow.FitView` animates its change
instead of jumping (default `0`: at once), eased by the root's `easing`
([The viewport](/docs/concepts/viewport#animated-changes)). A press during an animation starts
the next one from where the view is. The example's buttons take 200 ms:

<Framework name="react">

```tsx
<Flow.ZoomIn duration={200} aria-label="Zoom in" className="control">
    <PlusIcon />
</Flow.ZoomIn>
<Flow.FitView duration={200} aria-label="Fit view" className="control">
    <MaximizeIcon />
</Flow.FitView>
```

</Framework>

<Framework name="vue">

```vue
<Flow.ZoomIn :duration="200" aria-label="Zoom in" class="control">
    <PlusIcon />
</Flow.ZoomIn>
<Flow.FitView :duration="200" aria-label="Fit view" class="control">
    <MaximizeIcon />
</Flow.FitView>
```

In Vue, `:duration="200"` and a plain `duration="200"` are the same: the attribute's text is taken
as its number (as the root's `pan-on-scroll-speed`).

</Framework>

<Framework name="svelte">

```svelte
<Flow.ZoomIn duration={200} aria-label="Zoom in" class="control">
    <PlusIcon />
</Flow.ZoomIn>
<Flow.FitView duration={200} aria-label="Fit view" class="control">
    <MaximizeIcon />
</Flow.FitView>
```

</Framework>

<Framework name="angular">

```html
<button flowZoomIn [duration]="200" aria-label="Zoom in" class="control">
    <svg lucidePlus aria-hidden="true"></svg>
</button>
<button flowFitView [duration]="200" aria-label="Fit view" class="control">
    <svg lucideMaximize aria-hidden="true"></svg>
</button>
```

</Framework>

## The zoom limits

The root's `minZoom` (default 0.5) and `maxZoom` (default 2) bound every zoom, the buttons', the
wheel's and a pinch's:

<Framework name="react">

```tsx
<Flow.Root minZoom={0.25} maxZoom={2} zoomStep={1.5} fitView={{ padding: 0.1 }} … />
```

</Framework>

<Framework name="vue">

```vue
<Flow.Root :min-zoom="0.25" :max-zoom="2" :zoom-step="1.5" :fit-view="{ padding: 0.1 }" … />
```

</Framework>

<Framework name="svelte">

```svelte
<Flow.Root minZoom={0.25} maxZoom={2} zoomStep={1.5} fitView={{ padding: 0.1 }} … />
```

</Framework>

</Framework>

## Buttons of your own

The buttons are thin over the engine: your own button does the same with `useFlow` (inside the
root) or a [flow ref](/docs/api/primitives/flow-ref) (outside):

<Framework name="react">

```tsx
import { useFlow, useViewport } from "@fragiola/flow-react";

function ZoomReadout() {
    const { engine } = useFlow();
    const { zoom } = useViewport();
    return (
        <button type="button" onClick={() => engine.run("zoom-to", { zoom: 1 })}>
            {Math.round(zoom * 100)}%
        </button>
    );
}
```

</Framework>

<Framework name="vue">

```vue title="zoom-readout.vue"
<script setup lang="ts">
import { useFlow, useViewport } from "@fragiola/flow-vue";

const { engine } = useFlow();
const viewport = useViewport();
</script>

<template>
    <button type="button" @click="engine.run('zoom-to', { zoom: 1 })">
        {{ Math.round(viewport.zoom * 100) }}%
    </button>
</template>
```

`useViewport` is a computed ref in Vue: a template unwraps it (`viewport.zoom`), a script reads
`viewport.value`.

</Framework>

<Framework name="svelte">

```svelte title="zoom-readout.svelte"
<script lang="ts">
    import { useFlow, useViewport } from "@fragiola/flow-svelte";

    const flow = useFlow();
    const viewport = useViewport();
</script>

<button type="button" onclick={() => flow.engine.run("zoom-to", { zoom: 1 })}>
    {Math.round(viewport.current.zoom * 100)}%
</button>
```

`useViewport` gives `{ current }` in Svelte: a template and a script both read
`viewport.current`, which follows the view.

</Framework>

<Framework name="angular">

```ts title="zoom-readout.ts"
import { Component, computed } from "@angular/core";
import { injectFlow, injectViewport } from "@fragiola/flow-angular";

// rendered inside [flowRoot]
@Component({
    selector: "app-zoom-readout",
    template: `<button type="button" (click)="reset()">{{ percent() }}%</button>`,
})
export class ZoomReadout {
    private readonly flow = injectFlow();
    private readonly viewport = injectViewport();
    protected readonly percent = computed(() => Math.round(this.viewport().zoom * 100));

    protected reset(): void {
        this.flow.engine.run("zoom-to", { zoom: 1 });
    }
}
```

`injectViewport` gives a signal in Angular: a template and a `computed` both read `viewport()`,
which follows the view, and only what reads it is checked again on a pan.

</Framework>

Other actions: `center-on { x, y, zoom? }`, `pan-by { x, y }`, `set-viewport { x?, y?, zoom? }`,
`fit-view { nodeIds, padding }` (fit only some nodes). See [The viewport](/docs/concepts/viewport).

## The minimap

`minimap()` is a feature; `MiniMap`, `MiniMapNode` and `MiniMapMask` come with it, on the same
entry:

<Framework name="react">

```tsx
import { MiniMap, MiniMapMask, MiniMapNode, minimap } from "@fragiola/flow-react/minimap";

const features = [selection(), drag(), minimap()] as const;

<MiniMap
    width={180}
    height={130}
    role="img"
    aria-label="Minimap of the route"
    className="absolute end-3 bottom-3 rounded border bg-palette-base"
>
    {(view) => (
        <>
            {view.nodes.map((node) => (
                <MiniMapNode
                    key={node.nodeId}
                    nodeId={node.nodeId}
                    className="fill-palette-line data-selected:fill-(--fl-edge-selected)"
                />
            ))}
            <MiniMapMask className="fill-(--fl-minimap-mask) stroke-(--fl-edge-selected)" />
        </>
    )}
</MiniMap>;
```

</Framework>

<Framework name="vue">

```vue
<script lang="ts">
import { MiniMap, MiniMapMask, MiniMapNode, minimap } from "@fragiola/flow-vue/minimap";

const features = [selection(), drag(), minimap()] as const;
</script>

<script setup lang="ts">
import { typedFlow } from "@fragiola/flow-vue";

const Flow = typedFlow<Types, typeof features>();
</script>

<template>
    <MiniMap
        v-slot="{ view }"
        :width="180"
        :height="130"
        role="img"
        aria-label="Minimap of the route"
        class="absolute end-3 bottom-3 rounded border bg-palette-base"
    >
        <MiniMapNode
            v-for="node in view.nodes"
            :key="node.nodeId"
            :node-id="node.nodeId"
            class="fill-palette-line data-selected:fill-(--fl-edge-selected)"
        />
        <MiniMapMask class="fill-(--fl-minimap-mask) stroke-(--fl-edge-selected)" />
    </MiniMap>
</template>
```

In Vue, the children function is `MiniMap`'s default scoped slot, `v-slot="{ view }"`.

</Framework>

<Framework name="svelte">

```svelte
<script module lang="ts">
    import { MiniMap, MiniMapMask, MiniMapNode, minimap } from "@fragiola/flow-svelte/minimap";

    const features = [selection(), drag(), minimap()] as const;
</script>

<script lang="ts">
    import { typedFlow } from "@fragiola/flow-svelte";

    const Flow = typedFlow<Types, typeof features>();
</script>

<MiniMap
    width={180}
    height={130}
    role="img"
    aria-label="Minimap of the route"
    class="absolute end-3 bottom-3 rounded border bg-palette-base"
>
    {#snippet children(view)}
        {#each view.nodes as node (node.nodeId)}
            <MiniMapNode nodeId={node.nodeId} class="fill-palette-line data-selected:fill-(--fl-edge-selected)" />
        {/each}
        <MiniMapMask class="fill-(--fl-minimap-mask) stroke-(--fl-edge-selected)" />
    {/snippet}
</MiniMap>
```

In Svelte, the children function is `MiniMap`'s `children` snippet, `{#snippet children(view)}`.

</Framework>

<Framework name="angular">

```ts
import { FLOW_MINIMAP, minimap } from "@fragiola/flow-angular/minimap";

const features = [selection(), drag(), minimap()] as const;
// the component imports FLOW and FLOW_MINIMAP
```

```html
<svg
    flowMiniMap
    #map="flowMiniMap"
    [width]="180"
    [height]="130"
    role="img"
    aria-label="Minimap of the route"
    class="absolute end-3 bottom-3 rounded border bg-palette-base"
>
    @for (node of map.state().view.nodes; track node.nodeId) {
        <!-- a minimap node leaves the document while it is not shown: wrap it in a group -->
        <svg:g>
            <svg:rect flowMiniMapNode [nodeId]="node.nodeId" class="fill-palette-line data-selected:fill-(--fl-edge-selected)" />
        </svg:g>
    }
    <svg:path flowMiniMapMask class="fill-(--fl-minimap-mask) stroke-(--fl-edge-selected)" />
</svg>
```

In Angular, the children function is the elements you write inside `flowMiniMap`, reading
`#map="flowMiniMap"`'s `map.state().view`; with no element written, it draws a node per node and
the mask. `map.state()` changes on every pan and drag step, and a template that reads it is
checked again with all of its views: in the template that renders the nodes, every node. Read it
in a component of its own on the minimap's element (`<svg flowMiniMap appMinimap>`, whose
component injects `FlowMiniMapDirective` and holds the `@for`), as the examples do.

</Framework>

Without children, `MiniMap` draws a `MiniMapNode` per node and the `MiniMapMask`, unstyled. It is
an SVG of `width` × `height` pixels (200 × 150 by default) whose view box holds every node and the
root's view. The mask covers the map but what the root shows (`fill-rule="evenodd"`): give it a
translucent fill.

## Pan and zoom from the minimap

| option | default | does |
| --- | --- | --- |
| `pannable` | `true` | a press or a drag on the minimap moves the view there |
| `zoomable` | `true` | the wheel over the minimap zooms the flow |
| `padding` | `0.1` | the share of the minimap's size kept free around the nodes and the view |
| `inversePan` | `false` | a drag moves the view the other way, as grabbing the flow, and a press does not centre it |
| `zoomStep` | `10` | how fast the wheel over the minimap zooms: `10` is the flow's own wheel, `20` twice as fast |

```ts
const features = [minimap({ zoomable: false, padding: 0.05 })] as const;
```

A `MiniMap`'s own `inversePan` and `zoomStep` props override the last two for the root, and its
click callback (`onClick`; Vue `@click`, Svelte `onclick`, Angular `(minimapClick)`) tells a tap
with the flow point under it: [Grab, wheel speed and
clicks](/docs/api/primitives/mini-map#grab-wheel-speed-and-clicks).

A node can be drawn your own way: the function's `view.nodes` gives each node's box in flow
coordinates (`x`, `y`, `width`, `height`), and `view.scale` the map's scale.
