The package paints nothing and ships no class names, so Tailwind styles it with ordinary
utilities. Everything below is plain Tailwind v4, the way this site's examples are written; no
plugin or preset is involved.

## State through `data-*` variants

Tailwind v4 turns every attribute into a variant. The primitives expose their state as
[`data-*` attributes](/docs/concepts/state-attributes), present or absent:

<Framework name="react">

```tsx
<Flow.Node<Types>
    node={node}
    className="min-w-28 select-none rounded-lg border border-palette-line bg-palette-base px-3 py-2 data-dragging:cursor-grabbing data-selected:border-palette-ring data-selected:ring-2 data-selected:ring-palette-ring/30 focus-visible:outline-2"
>
    {node.data.label}
    <Flow.Handle
        type="source"
        side="bottom"
        className="size-2.5 rounded-full border border-palette-line bg-palette-base data-valid:bg-green-500 data-invalid:bg-red-500"
    />
</Flow.Node>
```

</Framework>

<Framework name="vue">

```vue
<Flow.Node
    :node="node"
    class="min-w-28 select-none rounded-lg border border-palette-line bg-palette-base px-3 py-2 data-dragging:cursor-grabbing data-selected:border-palette-ring data-selected:ring-2 data-selected:ring-palette-ring/30 focus-visible:outline-2"
>
    {{ node.data.label }}
    <Flow.Handle
        type="source"
        side="bottom"
        class="size-2.5 rounded-full border border-palette-line bg-palette-base data-valid:bg-green-500 data-invalid:bg-red-500"
    />
</Flow.Node>
```

</Framework>

<Framework name="svelte">

```svelte
<Flow.Node
    {node}
    class="min-w-28 select-none rounded-lg border border-palette-line bg-palette-base px-3 py-2 data-dragging:cursor-grabbing data-selected:border-palette-ring data-selected:ring-2 data-selected:ring-palette-ring/30 focus-visible:outline-2"
>
    {node.data.label}
    <Flow.Handle
        type="source"
        side="bottom"
        class="size-2.5 rounded-full border border-palette-line bg-palette-base data-valid:bg-green-500 data-invalid:bg-red-500"
    />
</Flow.Node>
```

</Framework>

<Framework name="angular">

```html
<div
    [flowNode]="node"
    class="min-w-28 select-none rounded-lg border border-palette-line bg-palette-base px-3 py-2 data-dragging:cursor-grabbing data-selected:border-palette-ring data-selected:ring-2 data-selected:ring-palette-ring/30 focus-visible:outline-2"
>
    {{ node.data.label }}
    <div
        flowHandle
        type="source"
        side="bottom"
        class="size-2.5 rounded-full border border-palette-line bg-palette-base data-valid:bg-green-500 data-invalid:bg-red-500"
    ></div>
</div>
```

</Framework>

Valued attributes take the bracket form: `data-[side=left]:-translate-x-1/2`,
`data-[handle-type=target]:rounded-none`, `data-[position=top-left]:cursor-nwse-resize`.

## SVG parts

Edges, the connection line, the background and the minimap are SVG: use the `stroke-*` and
`fill-*` utilities.

<Framework name="react">

```tsx
<Flow.EdgePath className="fill-none stroke-palette-line stroke-[1.5px] data-selected:stroke-palette-ring data-selected:stroke-[2.5px]" />
<Flow.ConnectionLine className="fill-none stroke-palette-ring [stroke-dasharray:4_3]" />
<Flow.Background variant="dots" size={2} className="text-palette-line" />
```

</Framework>

<Framework name="vue">

```vue
<Flow.EdgePath class="fill-none stroke-palette-line stroke-[1.5px] data-selected:stroke-palette-ring data-selected:stroke-[2.5px]" />
<Flow.ConnectionLine class="fill-none stroke-palette-ring [stroke-dasharray:4_3]" />
<Flow.Background variant="dots" :size="2" class="text-palette-line" />
```

</Framework>

<Framework name="svelte">

```svelte
<Flow.EdgePath class="fill-none stroke-palette-line stroke-[1.5px] data-selected:stroke-palette-ring data-selected:stroke-[2.5px]" />
<Flow.ConnectionLine class="fill-none stroke-palette-ring [stroke-dasharray:4_3]" />
<Flow.Background variant="dots" size={2} class="text-palette-line" />
```

</Framework>

<Framework name="angular">

```html
<svg:path flowEdgePath class="fill-none stroke-palette-line stroke-[1.5px] data-selected:stroke-palette-ring data-selected:stroke-[2.5px]" />
<svg flowConnectionLine class="fill-none stroke-palette-ring [stroke-dasharray:4_3]"></svg>
<svg flowBackground variant="dots" [size]="2" class="text-palette-line"></svg>
```

</Framework>

`Flow.Background` draws its marks in `currentColor`: its `text-*` utility is the marks' colour.

## State of an ancestor: `group` and `in-data-*`

A part inside a node styles itself from the node's state with a `group` on the node:

<Framework name="react">

```tsx
<Flow.Node<Types> node={node} className="group node">
    <span className="opacity-60 group-data-selected:opacity-100">{node.data.label}</span>
    <NodeResizer className="hidden group-data-selected:block" />
</Flow.Node>
```

</Framework>

<Framework name="vue">

```vue
<Flow.Node :node="node" class="group node">
    <span class="opacity-60 group-data-selected:opacity-100">{{ node.data.label }}</span>
    <NodeResizer class="hidden group-data-selected:block" />
</Flow.Node>
```

</Framework>

<Framework name="svelte">

```svelte
<Flow.Node {node} class="group node">
    <span class="opacity-60 group-data-selected:opacity-100">{node.data.label}</span>
    <NodeResizer class="hidden group-data-selected:block" />
</Flow.Node>
```

</Framework>

<Framework name="angular">

```html
<div [flowNode]="node" class="group node">
    <span class="opacity-60 group-data-selected:opacity-100">{{ node.data.label }}</span>
    <div flowNodeResizer class="hidden group-data-selected:block"></div>
</div>
```

</Framework>

`in-data-dragging:opacity-80` (Tailwind v4's `in-*` variant) does the same without naming the
group: it matches when any ancestor carries the attribute, such as the root while a drag is under
way.

## Class name functions

`className` also takes a function of the primitive's state: useful when the state is not an
attribute, or for a lookup of your own.

<Framework name="react">

```tsx
const TONE = { draft: "border-dashed", ready: "border-solid" } as const;

<Flow.Node<Types>
    node={node}
    className={(state) => `node ${TONE[state.node.data.status]} ${state.measured ? "" : "invisible"}`}
>
    {node.data.label}
</Flow.Node>;
```

</Framework>

<Framework name="vue">

```vue
<script setup lang="ts">
const TONE = { draft: "border-dashed", ready: "border-solid" } as const;
</script>

<template>
    <Flow.Nodes v-slot="{ node }">
        <Flow.Node :node="node" :class="['node not-data-measured:invisible', TONE[node.data.status]]">
            {{ node.data.label }}
        </Flow.Node>
    </Flow.Nodes>
</template>
```

Vue has no class function: `class` takes Vue's forms only (a string, an array, an object). A
lookup of your own reads the node the slot gives, and the state reads its `data-*` attribute
(`not-data-measured:invisible`); for anything else, the `render` slot gives the `state`.

</Framework>

<Framework name="svelte">

```svelte
<script lang="ts">
    const TONE = { draft: "border-dashed", ready: "border-solid" } as const;
</script>

<Flow.Nodes>
    {#snippet children(node)}
        <Flow.Node {node} class={(state) => ["node", TONE[state.node.data.status], !state.measured && "invisible"]}>
            {node.data.label}
        </Flow.Node>
    {/snippet}
</Flow.Nodes>
```

In Svelte, a class function of the state works as in React, and returns any of Svelte's class
forms: here an array, whose falsy entries are dropped.

</Framework>

<Framework name="angular">

```ts
export class TaskNodes {
    // complete class names, so Tailwind finds them
    protected readonly tone = { draft: "border-dashed", ready: "border-solid" } as const;
}
```

```html
<div flowNodes>
    <ng-template [flowNodesItem]="model" let-node>
        <div [flowNode]="node" #n="flowNode" class="node" [class]="tone[node.data.status]" [class.invisible]="!n.state()?.measured">
            {{ node.data.label }}
        </div>
    </ng-template>
</div>
```

In Angular, a class from the state is your `[class.x]` binding over the part's `state()`; a class
from the node's data is a `[class]` binding beside your static `class` (Angular merges them).

</Framework>

## One string per part

The examples keep every class string out of the markup, in a `styles.ts` beside the component:
one entry per part, read from the theme's tokens. The markup stays readable, and a theme changes
the look without touching it.

```ts title="styles.ts"
export const styles = {
    root: "size-full min-h-0 bg-(--fl-canvas-bg) font-(family-name:--fl-font) text-palette-contrast",
    node: "palette-raised min-w-28 select-none rounded-(--fl-node-radius) border-(length:--fl-node-border) border-(--fl-node-line) bg-(--fl-node-bg) p-(--fl-node-padding) data-selected:border-(--fl-edge-selected)",
    handle: "size-(--fl-handle-size) rounded-(--fl-handle-radius) border-(length:--fl-handle-border) border-(--fl-handle-line) bg-(--fl-handle-bg) data-valid:bg-(--fl-valid) data-invalid:bg-(--fl-invalid)",
    edge: "fill-none stroke-(--fl-edge-color) stroke-(length:--fl-edge-width) data-selected:stroke-(--fl-edge-selected)",
};
```

See [Theming with Fragiola palettes](/docs/guides/theming) for the tokens.

## Placing the overlays

`Flow.Controls`, `MiniMap` and your own panels sit inside the root, which is `position: relative`:
place them with `absolute` and logical insets (`bottom-3 start-3`, `bottom-3 end-3`). A panel of
your own over the canvas marks itself `data-flow-no-gesture` (and `data-flow-no-wheel` when it
scrolls), so a press on it never pans the flow.
