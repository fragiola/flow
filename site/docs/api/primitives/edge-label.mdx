---
title: EdgeLabel
description: Flow.EdgeLabel is HTML centred on an edge's label point, in flow coordinates, so it pans and zooms with the edge it names.
---

`Flow.EdgeLabel` goes inside `Flow.Edge` and is portalled into the HTML layer of `Flow.Edges`
(SVG holds no HTML), centred on the path's label point: halfway along the path, in flow
coordinates. It renders only its children (text from the edge's data, a badge, a button). A press
on it selects its edge; a button in it keeps its own clicks.

<Example id="edge-labels" />

<Framework name="react">

```tsx
<Flow.Edge<Types> edge={edge}>
    <Flow.EdgePath />
    <Flow.EdgeLabel className="rounded bg-white px-1 text-xs">{edge.data?.text}</Flow.EdgeLabel>
</Flow.Edge>
```

</Framework>

<Framework name="vue">

```vue
<Flow.Edge :edge="edge">
    <Flow.EdgePath />
    <Flow.EdgeLabel class="rounded bg-white px-1 text-xs">{{ edge.data?.text }}</Flow.EdgeLabel>
</Flow.Edge>
```

In Vue, `Flow.EdgeLabel` renders nothing where it is written: it hands its content to
`Flow.Edges`, whose HTML layer renders it with its edge (a `Teleport` out of an SVG would keep
creating SVG elements). Its default slot gets `{ state }`; a template `ref` on it reaches no element,
so read the element through its `render` slot.

</Framework>

<Framework name="svelte">

```svelte
<Flow.Edge {edge}>
    <Flow.EdgePath />
    <Flow.EdgeLabel class="rounded bg-white px-1 text-xs">{edge.data?.text}</Flow.EdgeLabel>
</Flow.Edge>
```

In Svelte, `Flow.EdgeLabel` mounts its element in `Flow.Edges`' HTML layer (Svelte has no
portal: it is mounted there with every context of its place, and unmounted with it), so HTML
content works inside an SVG edge. Its `children` snippet gets `{ state }`; `bind:ref` and an
attachment reach the mounted element.

</Framework>

<Framework name="angular">

```html
<svg:g [flowEdge]="edge">
    <svg:path flowEdgePath />
    <xhtml:div flowEdgeLabel class="rounded bg-white px-1 text-xs">{{ edge.data?.text }}</xhtml:div>
</svg:g>
```

In Angular, write the label inside the edge's SVG group with the `xhtml:` prefix (an HTML
element): `flowEdgeLabel` moves its element into `flowEdges`' HTML layer (Angular has no portal),
a comment keeping its place, so HTML content works inside an SVG edge and your bindings and
listeners keep working. Its state is the `state()` signal (`#l="flowEdgeLabel"`).

</Framework>

## Props

`EdgeLabelProps` extends the [common primitive props](/docs/api/primitives/root#common-props) and
every `div` attribute.

| prop | type | default | description |
| --- | --- | --- | --- |
| `edgeId` | `string` | the enclosing `Flow.Edge`'s | the edge |
| `children` | `ReactNode` | none | the label |

## State

`EdgeLabelState`, what `className`, `style` and `render` receive:

| field | type | description |
| --- | --- | --- |
| `edgeId` | `string` | the edge |
| `path` | `EdgePath` | the path, its label point and its ends |
| `selected` | `boolean` | the edge is selected |

## Data attributes

| attribute | value |
| --- | --- |
| `data-flow-part` | `"edge-label"` |
| `data-flow-id` | the edge's id |
| `data-selected` | present while the edge is selected |
| `data-animated` | present while the edge's `animated` flag is set |

## Structural style

`position: absolute; top: 0; left: 0; transform: translate(<x>px, <y>px) translate(-50%, -50%)` at the label point,
and `pointer-events: all`.
