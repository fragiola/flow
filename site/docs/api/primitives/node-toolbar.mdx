---
title: NodeToolbar
description: Flow.NodeToolbar places your buttons next to a node, outside the zoom so they keep their size, shown while the node is selected by default.
---

`Flow.NodeToolbar` goes inside `Flow.Node` (or anywhere in the root with a `nodeId`). It is
portalled into `Flow.Root`, outside the zoom, at the anchor `node-toolbar-by` gives: on the node's
`side`, aligned to its `align`, `offset` pixels away. So it keeps its size at any zoom and follows
the node as it moves. By default it is shown while its node is selected (`selection()`); `open`
decides instead. With `nodeIds` it stands beside several nodes' bounds (a toolbar for the
selection), anywhere in the root, shown while every one of them is selected. Presses and the wheel
over it are left to it. It renders only your children.

<Example id="node-toolbar" />

<Framework name="react">

```tsx
function Toolbar({ node }: { node: FlowNode<Types> }) {
    const { model } = useFlow<Types, typeof features>();
    return (
        <Flow.NodeToolbar role="toolbar" aria-label={`${node.data.text}: actions`} side="top" offset={8}>
            <button type="button" aria-label="Delete" onClick={() => model.run("node.remove", { nodeId: node.id })}>
                <Trash2Icon />
            </button>
        </Flow.NodeToolbar>
    );
}
```

</Framework>

<Framework name="vue">

```vue title="toolbar.vue"
<script setup lang="ts">
import { type FlowNode, useFlow } from "@fragiola/flow-vue";
import { Trash2Icon } from "@lucide/vue";

const props = defineProps<{ node: FlowNode<Types> }>();
const { model } = useFlow<Types, typeof features>();
</script>

<template>
    <Flow.NodeToolbar role="toolbar" :aria-label="`${node.data.text}: actions`" side="top" :offset="8">
        <button type="button" aria-label="Delete" @click="model.run('node.remove', { nodeId: props.node.id })">
            <Trash2Icon />
        </button>
    </Flow.NodeToolbar>
</template>
```

In Vue, it is a `Teleport` to the root's element; a bare `open` attribute is `true`. Its element
renders elsewhere, so a template `ref` on it reaches no element: use its `render` slot.

</Framework>

<Framework name="svelte">

```svelte title="toolbar.svelte"
<script lang="ts">
    import { Flow, type FlowNode, useFlow } from "@fragiola/flow-svelte";
    import { Trash2Icon } from "@lucide/svelte";

    let { node }: { node: FlowNode<Types> } = $props();
    const flow = useFlow<Types, typeof features>();
</script>

<Flow.NodeToolbar role="toolbar" aria-label="{node.data.text}: actions" side="top" offset={8}>
    <button type="button" aria-label="Delete" onclick={() => flow.model.run("node.remove", { nodeId: node.id })}>
        <Trash2Icon />
    </button>

```

In Svelte, its element is mounted in the root's element (Svelte has no portal: it is mounted
there with every context of its place, and unmounted with it); `bind:ref` reaches it.

</Framework>

<Framework name="angular">

```ts title="toolbar.ts"
import { Component, input } from "@angular/core";
import { FLOW, type FlowNode, injectFlow } from "@fragiola/flow-angular";
import { LucideTrash2 } from "@lucide/angular";

// rendered inside [flowNode]: <app-toolbar [node]="node" />
@Component({
    selector: "app-toolbar",
    imports: [FLOW, LucideTrash2],
    template: `
        <div flowNodeToolbar role="toolbar" [attr.aria-label]="node().data.text + ': actions'" side="top" [offset]="8">
            <button type="button" aria-label="Delete" (click)="remove()">
                <svg lucideTrash2 aria-hidden="true"></svg>
            </button>
        </div>
    `,
})
export class Toolbar {
    readonly node = input.required<FlowNode<Types>>();
    private readonly flow = injectFlow<Types, typeof features>();

    protected remove(): void {
        this.flow.model().run("node.remove", { nodeId: this.node().id });
    }
}
```

In Angular, the toolbar moves its element into the root's element (Angular has no portal), a
comment keeping its place; it leaves the document while it is not open. Your bindings, listeners
and `injectFlow` keep working there.

</Framework>

A toolbar has no role: give it `role="toolbar"` and a label when it holds several buttons.

## Side and alignment

`side` is the node's side the toolbar stands on, and `align` where along it: `"start"` (the left
of a top or bottom side, the top of a left or right one), `"center"` (the default) or `"end"`.
`offset` is the gap in pixels. A toolbar below a node, flush with its right edge:

<Framework name="react">

```tsx
<Flow.NodeToolbar side="bottom" align="end" offset={6}>…</Flow.NodeToolbar>
```

</Framework>

<Framework name="vue">

```vue
<Flow.NodeToolbar side="bottom" align="end" :offset="6">…</Flow.NodeToolbar>
```

</Framework>

<Framework name="svelte">

```svelte
<Flow.NodeToolbar side="bottom" align="end" offset={6}>…</Flow.NodeToolbar>
```

</Framework>

<Framework name="angular">

```html
<div flowNodeToolbar side="bottom" align="end" [offset]="6">…</div>
```

## Props

`NodeToolbarProps` extends the [common primitive props](/docs/api/primitives/root#common-props) and
every `div` attribute.

| prop | type | default | description |
| --- | --- | --- | --- |
| `nodeId` | `string` | the enclosing `Flow.Node`'s | its node |
| `nodeIds` | `readonly string[]` | none | several nodes it stands beside (their bounds) instead of one: when not empty it wins over `nodeId`, needs no enclosing node, and the toolbar is shown while every one of them is selected |
| `side` | `HandleSide` | `"top"` | the node's side it stands on |
| `align` | `"start" \| "center" \| "end"` | `"center"` | where along that side |
| `offset` | `number` | `10` | the gap between the node and the toolbar, in pixels |
| `open` | `boolean` | while its node (every node of `nodeIds`) is selected | whether it is shown |
| `children` | `ReactNode` | none | your buttons |

## State

`NodeToolbarState`, what `className`, `style` and `render` receive:

| field | type | description |
| --- | --- | --- |
| `nodeId` | `string \| undefined` | its node (undefined for several nodes' toolbar) |
| `nodeIds` | `readonly string[]` | the nodes it stands beside: `nodeIds`, or its one node |
| `position` | `NodeToolbarPosition` | its anchor, in pixels relative to the root ([engine reads](/docs/api/engine)) |
| `side` | `HandleSide` | the side it stands on |

## Data attributes

| attribute | value |
| --- | --- |
| `data-flow-part` | `"toolbar"` |
| `data-flow-id` | its node's id (none for several nodes') |

## Structural style

`position: absolute; top: 0; left: 0; transform: translate(<x>px, <y>px) translate(<-anchorX × 100>%, <-anchorY × 100>%)`
at its anchor.
