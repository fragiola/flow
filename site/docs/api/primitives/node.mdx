---
title: Node
description: Flow.Node renders one node at its place in the flow, registers it with the engine to be measured, and holds its content, handles and toolbar.
---

`Flow.Node` renders the node `Flow.Nodes` gives its children function. It is absolutely positioned
at the node's place (a structural `transform: translate(x, y)` from `node-rect-by`, absolute even
in a sub-flow: a child is not nested in its parent's element), with the document's `width` and
`height` when it gives them. It registers its element with the engine, which measures it
(`ResizeObserver`) and resolves presses on it: a drag (`drag()`), a click selects
(`selection()`), a press on one of its handles draws a connection (`connection()`). With
`keyboard()` it takes `tabIndex={0}`.

It renders only its children: the content, `Flow.Handle`s, a `NodeResizer`, a
`Flow.NodeToolbar`. Fields, buttons and links inside it start no gesture, nor does an element
marked `data-flow-no-gesture`; `data-flow-no-wheel` keeps the wheel (a scrolling list).

<Framework name="react">

```tsx
<Flow.Nodes<Types>>
    {(node) => (
        <Flow.Node<Types>
            node={node}
            aria-label={node.data.label}
            className={(state) => (state.selected ? "node node-selected" : "node")}
        >
            {node.data.label}
            <Flow.Handle type="target" side="top" />
            <Flow.Handle type="source" side="bottom" />
        </Flow.Node>
    )}
</Flow.Nodes>
```

</Framework>

<Framework name="vue">

```vue
<Flow.Nodes v-slot="{ node }">
    <Flow.Node :node="node" :aria-label="node.data.label" class="node data-selected:node-selected">
        {{ node.data.label }}
        <Flow.Handle type="target" side="top" />
        <Flow.Handle type="source" side="bottom" />
    </Flow.Node>
</Flow.Nodes>
```

In Vue, `class` takes no function of the state: style the state through its `data-*` attributes
(`data-selected:`), or read `{ state }` from its default slot
(`<Flow.Node :node="node" v-slot="{ state }">`). A template `ref` on it is the component, its `$el`
the node's element.

</Framework>

<Framework name="svelte">

```svelte
<Flow.Nodes>
    {#snippet children(node)}
        <Flow.Node {node} aria-label={node.data.label} class={(state) => ["node", state.selected && "node-selected"]}>
            {node.data.label}
            <Flow.Handle type="target" side="top" />
            <Flow.Handle type="source" side="bottom" />
        </Flow.Node>
    {/snippet}
</Flow.Nodes>
```

In Svelte, `class` and `style` take a value or a function of the state, as in React (`class`
takes any of Svelte's forms: a string, an array, an object); `bind:ref` is the node's element.

</Framework>

<Framework name="angular">

```html
<div flowNodes>
    <ng-template [flowNodesItem]="model" let-node>
        <div [flowNode]="node" #n="flowNode" [attr.aria-label]="node.data.label" class="node" [class.node-selected]="n.state()?.selected">
            {{ node.data.label }}
            <div flowHandle type="target" side="top"></div>
            <div flowHandle type="source" side="bottom"></div>
        </div>
    </ng-template>
</div>
```

In Angular, `flowNode` goes on your element (any element: `<article [flowNode]>`), its state is
the `state()` signal (`#n="flowNode"`), and a class from the state is your `[class.x]` binding.
`injectNode` binds a component's host as the node instead.

</Framework>

It has no role and no name: give it the ones your app means (see
[Accessible names](/docs/getting-started/accessible-names)), and `user-select: none` so a drag does
not select its text. For a node rendered by hand, [`useNode`](/docs/api/primitives/hooks) gives
the same state and props.

## Props

`NodeProps<T>` extends the [common primitive props](/docs/api/primitives/root#common-props) and
every `div` attribute.

| prop | type | default | description |
| --- | --- | --- | --- |
| `node` | `FlowNode<T>` | required | the node it renders: the one `Flow.Nodes` gives |
| `children` | `ReactNode` | none | its content, handles, resizer, toolbar |

## State

`NodeState<T>`, what `className`, `style` and `render` receive (also
[`useNode`](/docs/api/primitives/hooks)'s `state`):

| field | type | description |
| --- | --- | --- |
| `nodeId` | `string` | its id |
| `node` | `FlowNode<T>` | the node, as the model holds it |
| `x`, `y` | `number` | its top-left corner in absolute flow coordinates |
| `selected` | `boolean` | it is selected (`selection()`) |
| `dragging` | `boolean` | it is being dragged (`drag()`) |
| `resizing` | `boolean` | it is being resized (`resize()`) |
| `measured` | `boolean` | its size is known (measured or given) |
| `focusable` | `boolean` | it takes DOM focus (`keyboard()`) |
| `attributes` | `PartAttributes` | the attributes its element carries |

## Data attributes

| attribute | value |
| --- | --- |
| `data-flow-part` | `"node"` |
| `data-flow-id` | its id |
| `data-selected` | present while selected |
| `data-dragging` | present while dragged |
| `data-resizing` | present while resized |
| `data-measured` | present once its size is known |
| `data-hidden` | present when hidden: only on a node you render by hand with `useNode`, since `Flow.Nodes` leaves hidden nodes out |
| `tabindex` | `0` with `keyboard()` |

## Structural style

`position: absolute; top: 0; left: 0; transform: translate(<x>px, <y>px)` (its box's top-left
corner, its `origin` or the root's `nodeOrigin` applied), `z-index` (`node-z-index-by`: its
`zIndex`, raised by 10 000 while selected with `elevateNodesOnSelect`, at least its parent's + 1;
a negative rank while edges stand above nodes), and `width` / `height` when the document gives
them. Before the engine is attached (the first render, a server render) the same place and
`z-index` come from the document's [static geometry](/docs/guides/server-rendering), so nothing
moves when the engine takes over. Its look is yours.
