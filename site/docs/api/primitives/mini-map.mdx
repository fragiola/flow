---
title: MiniMap
description: MiniMap draws a small map of every node and of what the root shows; with minimap(), a drag on it pans the flow and its wheel zooms.
---

`MiniMap` comes from `@fragiola/flow-react/minimap` (`@fragiola/flow-vue/minimap`), with the `minimap()` feature it needs. It
renders an SVG of `width` × `height` pixels inside `Flow.Root`, outside `Flow.Viewport`, whose
view box is the engine's `minimap-view`: every node, and the view the root shows. By default it
draws a `MiniMapNode` per node, then the `MiniMapMask`; a children function receives the view
(`MinimapView`) to draw your own. With `minimap({ pannable, zoomable })` (both true by default) a
press or a drag on it pans the flow and its wheel zooms it. Place it and name it yourself.

<Example id="minimap-and-controls" />

<Framework name="react">

```tsx
import { Flow } from "@fragiola/flow-react";
import { MiniMap, MiniMapMask, MiniMapNode, minimap } from "@fragiola/flow-react/minimap";

const features = [minimap()] as const;

<Flow.Root<Types, typeof features> features={features} defaultNodes={nodes} className="relative size-full">
    <Flow.Viewport>…</Flow.Viewport>
    <MiniMap width={180} height={130} role="img" aria-label="Minimap" className="absolute right-3 bottom-3">
        {(view) => (
            <>
                {view.nodes.map((node) => (
                    <MiniMapNode key={node.nodeId} nodeId={node.nodeId} className="fill-gray-300" />
                ))}
                <MiniMapMask className="fill-black/10" />
            </>
        )}
    </MiniMap>
</Flow.Root>;
```

</Framework>

<Framework name="vue">

```vue
<script setup lang="ts">
import { typedFlow } from "@fragiola/flow-vue";
import { MiniMap, MiniMapMask, MiniMapNode, minimap } from "@fragiola/flow-vue/minimap";

const features = [minimap()] as const;
const Flow = typedFlow<Types, typeof features>();
</script>

<template>
    <Flow.Root :features="features" :default-nodes="nodes" class="relative size-full">
        <Flow.Viewport>…</Flow.Viewport>
        <MiniMap
            v-slot="{ view }"
            :width="180"
            :height="130"
            role="img"
            aria-label="Minimap"
            class="absolute right-3 bottom-3"
        >
            <MiniMapNode v-for="node in view.nodes" :key="node.nodeId" :node-id="node.nodeId" class="fill-gray-300" />
            <MiniMapMask class="fill-black/10" />
        </MiniMap>
    </Flow.Root>
</template>
```

In Vue, the children function is the default scoped slot, `v-slot="{ view }"`.

</Framework>

<Framework name="svelte">

```svelte
<script lang="ts">
    import { typedFlow } from "@fragiola/flow-svelte";
    import { MiniMap, MiniMapMask, MiniMapNode, minimap } from "@fragiola/flow-svelte/minimap";

    const features = [minimap()] as const;
    const Flow = typedFlow<Types, typeof features>();

<Flow.Root {features} defaultNodes={nodes} class="relative size-full">
    <Flow.Viewport>…</Flow.Viewport>
    <MiniMap width={180} height={130} role="img" aria-label="Minimap" class="absolute right-3 bottom-3">
        {#snippet children(view)}
            {#each view.nodes as node (node.nodeId)}
                <MiniMapNode nodeId={node.nodeId} class="fill-gray-300" />
            {/each}
            <MiniMapMask class="fill-black/10" />
        {/snippet}
    </MiniMap>
</Flow.Root>
```

In Svelte, the children function is the `children` snippet, `{#snippet children(view)}`.

</Framework>

<Framework name="angular">

```ts
import { FLOW_MINIMAP, minimap } from "@fragiola/flow-angular/minimap";

const features = [minimap()] as const;
// the component imports FLOW and FLOW_MINIMAP
```

```html
<div flowRoot [features]="features" [defaultNodes]="nodes" class="relative size-full">
    <div flowViewport>…</div>
    <svg flowMiniMap #map="flowMiniMap" [width]="180" [height]="130" role="img" aria-label="Minimap" class="absolute right-3 bottom-3">
        @for (node of map.state().view.nodes; track node.nodeId) {
            <svg:g><svg:rect flowMiniMapNode [nodeId]="node.nodeId" class="fill-gray-300" /></svg:g>
        }
        <svg:path flowMiniMapMask class="fill-black/10" />
    </svg>
</div>
```

In Angular, the children function is the elements you write inside `flowMiniMap`, reading
`#map="flowMiniMap"`'s `map.state().view`; with no element written, it draws a node per node and
the mask. `map.state()` changes on every pan and drag step, and a template that reads it is
checked again with all of its views: in the template that renders the nodes, every node. Read it
in a component of its own on the minimap's element (`<svg flowMiniMap appMinimap>`, whose
component injects `FlowMiniMapDirective` and holds the `@for`), as the examples do. A minimap node leaves the document while it is not shown, so wrap each one in a group
when it would be the first element of an `@for`'s view.

</Framework>

## Props

`MiniMapProps` extends the [common primitive props](/docs/api/primitives/root#common-props) and
every SVG attribute of an `svg` but `children`.

| prop | type | default | description |
| --- | --- | --- | --- |
| `width` | `number` | `200` | its width, in pixels |
| `height` | `number` | `150` | its height, in pixels |
| `children` | `ReactNode \| ((view: MinimapView) => ReactNode)` | a `MiniMapNode` per node, then the `MiniMapMask` | what it draws, in flow coordinates |

## State

`MiniMapState`, what `className`, `style` and `render` receive:

| field | type | description |
| --- | --- | --- |
| `view` | `MinimapView` | the nodes, the view and the mask, in flow coordinates ([engine reads](/docs/api/engine)) |

## Data attributes

| attribute | value |
| --- | --- |
| `data-flow-part` | `"minimap"` |

## Structural style

`width` and `height` (attributes and style), `viewBox` from `minimap-view`.
