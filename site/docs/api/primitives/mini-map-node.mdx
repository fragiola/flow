---
title: MiniMapNode
description: MiniMapNode is one node in the MiniMap, a rectangle of the node's box in flow coordinates, marked while the node is selected.
---

`MiniMapNode` comes from `@fragiola/flow-react/minimap` (`@fragiola/flow-vue/minimap`) and goes inside `MiniMap`. It renders an
SVG `rect` of its node's box from the minimap's view, in flow coordinates, and nothing when the
node is not shown. Give it its fill, through `data-selected` for the selected look.

<Framework name="react">

```tsx
<MiniMap>
    {(view) =>
        view.nodes.map((node) => (
            <MiniMapNode key={node.nodeId} nodeId={node.nodeId} className="fill-gray-300 data-selected:fill-blue-500" />
        ))
    }
</MiniMap>
```

</Framework>

<Framework name="vue">

```vue
<MiniMap v-slot="{ view }">
    <MiniMapNode
        v-for="node in view.nodes"
        :key="node.nodeId"
        :node-id="node.nodeId"
        class="fill-gray-300 data-selected:fill-blue-500"
    />
</MiniMap>
```

</Framework>

<Framework name="svelte">

```svelte
<MiniMap>
    {#snippet children(view)}
        {#each view.nodes as node (node.nodeId)}
            <MiniMapNode nodeId={node.nodeId} class="fill-gray-300 data-selected:fill-blue-500" />
        {/each}
    {/snippet}
</MiniMap>
```

</Framework>

<Framework name="angular">

```html
<svg flowMiniMap #map="flowMiniMap">
    @for (node of map.state().view.nodes; track node.nodeId) {
        <svg:g><svg:rect flowMiniMapNode [nodeId]="node.nodeId" class="fill-gray-300 data-selected:fill-blue-500" /></svg:g>
    }
</svg>
```

In Angular, a minimap node leaves the document while its node is not shown: wrap it (here in an
`<svg:g>`) when it would be the first element of an `@for`'s view.

</Framework>

## Props

`MiniMapNodeProps` extends the [common primitive props](/docs/api/primitives/root#common-props) and
every SVG attribute of a `rect`.

| prop | type | default | description |
| --- | --- | --- | --- |
| `nodeId` | `string` | required | the node it stands for |

## State

`MiniMapNodeState`, what `className`, `style` and `render` receive:

| field | type | description |
| --- | --- | --- |
| `nodeId` | `string` | the node |
| `selected` | `boolean` | the node is selected (`selection()`) |

## Data attributes

| attribute | value |
| --- | --- |
| `data-flow-part` | `"minimap-node"` |
| `data-flow-id` | the node's id |
| `data-selected` | present while the node is selected |
