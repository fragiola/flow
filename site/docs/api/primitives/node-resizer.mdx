---
title: NodeResizer
description: NodeResizer holds the resize handles of a node, with that node's own size limits and aspect ratio over the resize() feature's.
---

`NodeResizer` comes from `@fragiola/flow-react/resize` (`@fragiola/flow-vue/resize`), with the `resize()` feature it needs. It
must be rendered inside its node's element (`Flow.Node`): the engine finds the node a press
resizes from the DOM, the closest node part, and `nodeId` only names the node for the state and
the limits. It and renders a box over the node holding its `ResizeHandle`s: by default
one at each corner and side. A drag on a handle resizes the node (`node.resize`, transient steps
then a final one), within this node's limits, which override `resize()`'s
(`engine.adapter.setPartOptions("resizer", nodeId, …)`). In a sub-flow, a child with `extent: "parent"`
stays inside its parent, and a parent never shrinks past its `extent: "parent"` children. Render it only when the node should be
resizable (while it is selected, say).

<Example id="node-resizer" />

<Framework name="react">

```tsx title="resizable-node.tsx"
import { Flow, type FlowNode, type FlowTypes } from "@fragiola/flow-react";
import { drag } from "@fragiola/flow-react/drag";
import { NodeResizer, resize } from "@fragiola/flow-react/resize";
import { selection } from "@fragiola/flow-react/selection";

interface Types extends FlowTypes {
    readonly nodes: { note: { label: string } };
}

export const features = [selection(), drag(), resize({ minWidth: 80, minHeight: 60 })] as const;

export function ResizableNode({ node }: { node: FlowNode<Types> }) {
    return (
        <Flow.Node<Types> node={node} className="relative">
            {node.data.label}
            {node.selected && <NodeResizer minWidth={120} maxWidth={360} keepAspectRatio={false} />}
        </Flow.Node>
    );
}
```

</Framework>

<Framework name="vue">

```vue title="resizable-node.vue"
<script lang="ts">
import type { FlowTypes } from "@fragiola/flow-vue";
import { drag } from "@fragiola/flow-vue/drag";
import { resize } from "@fragiola/flow-vue/resize";
import { selection } from "@fragiola/flow-vue/selection";

export interface Types extends FlowTypes {
    readonly nodes: { note: { label: string } };
}

export const features = [selection(), drag(), resize({ minWidth: 80, minHeight: 60 })] as const;
</script>

<script setup lang="ts">
import { type FlowNode, typedFlow } from "@fragiola/flow-vue";
import { NodeResizer } from "@fragiola/flow-vue/resize";

const Flow = typedFlow<Types, typeof features>();
defineProps<{ node: FlowNode<Types> }>();
</script>

<template>
    <Flow.Node :node="node" class="relative">
        {{ node.data.label }}
        <NodeResizer v-if="node.selected" :min-width="120" :max-width="360" :keep-aspect-ratio="false" />
    </Flow.Node>
</template>
```

In Vue, `NodeResizer` comes from `@fragiola/flow-vue/resize`; its limits are kebab-case
(`:min-width`), a bare `keep-aspect-ratio` attribute is `true`, and its default slot (its
handles) gets `{ state }`.

</Framework>

## Props

`NodeResizerProps` extends the [common primitive props](/docs/api/primitives/root#common-props) and
every `div` attribute.

| prop | type | default | description |
| --- | --- | --- | --- |
| `nodeId` | `string` | the enclosing `Flow.Node`'s | the node its state and its limits name (the node a press resizes is the one it is rendered in) |
| `minWidth` | `number` | `resize()`'s (`10`) | this node's smallest width, in flow units |
| `minHeight` | `number` | `resize()`'s (`10`) | this node's smallest height |
| `maxWidth` | `number` | `resize()`'s (none) | this node's largest width |
| `maxHeight` | `number` | `resize()`'s (none) | this node's largest height |
| `keepAspectRatio` | `boolean` | `resize()`'s (`false`) | this node keeps its width-to-height ratio |
| `children` | `ReactNode` | a `ResizeHandle` at each corner and side | its handles |

## State

`NodeResizerState`, what `className`, `style` and `render` receive:

| field | type | description |
| --- | --- | --- |
| `nodeId` | `string` | its node |
| `resizing` | `boolean` | its node is being resized |

## Data attributes

| attribute | value |
| --- | --- |
| `data-flow-part` | `"resizer"` |
| `data-flow-id` | its node's id |
| `data-resizing` | present while its node is resized |

## Structural style

`position: absolute; inset: 0; pointer-events: none` (its handles take the presses).
