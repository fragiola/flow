---
title: NodeResizer
description: NodeResizer holds the resize handles of a node, with that node's own size limits and aspect ratio over the resize() feature's.
---

`NodeResizer` comes from `@fragiola/flow-react/resize`, with the `resize()` feature it needs. It
goes inside `Flow.Node` and renders a box over the node holding its `ResizeHandle`s: by default
one at each corner and side. A drag on a handle resizes the node (`node.resize`, transient steps
then a final one), within this node's limits, which override `resize()`'s
(`engine.adapter.setPartOptions("resizer", nodeId, …)`). In a sub-flow, a child stays inside its
parent and a parent never shrinks past its children. Render it only when the node should be
resizable (while it is selected, say).

<Example id="node-resizer" />

```tsx
import { NodeResizer, resize } from "@fragiola/flow-react/resize";

const features = [selection(), drag(), resize({ minWidth: 80, minHeight: 60 })] as const;

<Flow.Node<Types> node={node} className="relative">
    {node.data.label}
    {node.selected && <NodeResizer minWidth={120} maxWidth={360} keepAspectRatio={false} />}
</Flow.Node>;
```

## Props

`NodeResizerProps` extends the [common primitive props](/docs/api/primitives/root#common-props) and
every `div` attribute.

| prop | type | default | description |
| --- | --- | --- | --- |
| `nodeId` | `string` | the enclosing `Flow.Node`'s | its node |
| `minWidth` | `number` | `resize()`'s (`10`) | this node's smallest width, in flow units |
| `minHeight` | `number` | `resize()`'s (`10`) | this node's smallest height |
| `maxWidth` | `number` | `resize()`'s (none) | this node's largest width |
| `maxHeight` | `number` | `resize()`'s (none) | this node's largest height |
| `keepAspectRatio` | `boolean` | `resize()`'s (`false`) | this node keeps its width-to-height ratio |
| `children` | `ReactNode` | a `ResizeHandle` at each corner and side | its handles |

## State

`NodeResizerState`, what `className`, `style` and `render` receive:

| field | type | description |
| --- | --- | --- |
| `nodeId` | `string` | its node |
| `resizing` | `boolean` | its node is being resized |

## Data attributes

| attribute | value |
| --- | --- |
| `data-flow-part` | `"resizer"` |
| `data-flow-id` | its node's id |
| `data-resizing` | present while its node is resized |

## Structural style

`position: absolute; inset: 0; pointer-events: none` (its handles take the presses).
