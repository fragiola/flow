---
title: ToggleInteractive
description: Flow.ToggleInteractive is a toggle button that locks the flow, turning dragging, connecting and selecting off while pan and zoom keep working.
---

`Flow.ToggleInteractive` renders a `button` (`type="button"`) that locks and unlocks the flow
the way React Flow's interactive button does: locking runs `"set-interactive"` with `{ drag:
false, connect: false, select: false }` (no drag, no connection, no selection, nor their keys),
unlocking with those three and `interactive` on. Pan and zoom keep working, and so do resizing and
the delete keys (the root's `interactive={false}` stops those too). It is locked, `aria-pressed`,
while none of the three kinds is allowed (`engine.is("interactive-by", { kind })`, or the flow is
not `interactive`), and carries `data-interactive` while unlocked; it is disabled until the root is mounted. A `disabled` of yours replaces that rule (your props win), unlike the zoom and fit buttons, which stay disabled while their action is refused whatever you pass. It sets no text: switch its icon on
`state.interactive` and give it an `aria-label`.

<Framework name="react">

```tsx
import { LockIcon, UnlockIcon } from "lucide-react";

<Flow.ToggleInteractive
    aria-label="Lock the flow"
    render={(props, state) => <button {...props}>{state.interactive ? <UnlockIcon /> : <LockIcon />}</button>}
/>;
```

</Framework>

<Framework name="vue">

```vue
<script setup lang="ts">
import { LockIcon, UnlockIcon } from "@lucide/vue";
</script>

<template>
    <Flow.ToggleInteractive v-slot="{ state }" aria-label="Lock the flow">
        <UnlockIcon v-if="state.interactive" />
        <LockIcon v-else />
    </Flow.ToggleInteractive>
</template>
```

In Vue, its default slot gets `{ state }`, so the icon switches without replacing the button;
the `render` slot (`#render="{ props, state }"`) replaces it as React's `render` does.

</Framework>

<Framework name="svelte">

```svelte
<script lang="ts">
    import { LockIcon, UnlockIcon } from "@lucide/svelte";
</script>

<Flow.ToggleInteractive aria-label="Lock the flow">
    {#snippet children({ state })}
        {#if state.interactive}<UnlockIcon />{:else}<LockIcon />{/if}
    {/snippet}
</Flow.ToggleInteractive>
```

In Svelte, its `children` snippet gets `{ state }`, so the icon switches without replacing the
button; the `render` snippet (`{#snippet render({ props, state, children })}`) replaces it as
React's `render` does.

</Framework>

<Framework name="angular">

```html
<button flowToggleInteractive #lock="flowToggleInteractive" aria-label="Lock the flow">
    @if (lock.state().interactive) {
        <svg lucideLockOpen aria-hidden="true"></svg>
    } @else {
        <svg lucideLock aria-hidden="true"></svg>
    }
</button>
```

In Angular, the button is yours and its state is the `state()` signal, through its `exportAs`
(`#lock="flowToggleInteractive"`), so the icon switches without replacing the button.

</Framework>

The root's `interactive` prop locks the whole flow from your state (the toggle then shows locked,
and a click unlocks it whole); a root whose `interactive` does not change leaves the toggle's lock
alone.

## Props

`ToggleInteractiveProps` extends the [common primitive props](/docs/api/primitives/root#common-props)
and every `button` attribute.

| prop | type | default | description |
| --- | --- | --- | --- |
| `children` | `ReactNode` | none | its icon or label |

## State

`ToggleInteractiveState`, what `className`, `style` and `render` receive:

| field | type | description |
| --- | --- | --- |
| `interactive` | `boolean` | the flow is not locked: it is interactive and dragging, connecting or selecting is on |

## Data attributes

| attribute | value |
| --- | --- |
| `data-flow-part` | `"toggle-interactive"` |
| `data-interactive` | present while the flow is unlocked |
| `aria-pressed` | `true` while the flow is locked |
