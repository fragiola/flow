<Section eyebrow="What it ships" title="Behaviour and accessibility, nothing to restyle" description="Composable primitives over a framework-free core: everything that is not rendering lives in the core.">
<Features columns={3}>
<Feature title="Gestures">
Pan, wheel and pinch zoom, node drags with snapping, connections drawn from handles, edges
reconnected, box selection and resizing: one Pointer Events path for mouse, touch and pen.
</Feature>
<Feature title="A typed model">
The flow is one JSON document. Every change is a command with a JSON Schema, which middleware can
veto or rewrite and an assistant can call.
</Feature>
<Feature title="Rules as middleware">
A connection rule is a middleware on `edge.add`: the drag marks a refused handle `data-invalid`
before the drop, and code obeys the same rule.
</Feature>
<Feature title="Opt-in features">
Selection, drag, connection, reconnection, resizing, sub-flows, keyboard and the minimap, each on
its own entry: a flow ships only what it imports.
</Feature>
<Feature title="Accessible by design">
Focusable nodes and edges, arrow moves, Delete and Escape, and engine events your own live region
turns into words.
</Feature>
<Feature title="Your markup">
You render every node and edge with a children function (a scoped slot in Vue), and swap any
element with `render`: a `switch` on the node's type is your registry.
</Feature>
</Features>
</Section>

<Section eyebrow="What stays yours" title="What it never ships">
<Pills strike items={["CSS", "Icons", "Text", "Node components", "Undo and redo"]} />

The state is exposed as `data-*` attributes and ARIA, so any styling works: Tailwind, plain CSS,
CSS modules, CSS-in-JS. The examples use Fragiola UI and its palettes, and keep app policy (undo,
persistence) as code you copy.
</Section>

<Framework name="react">

```tsx title="pipeline.tsx"
import { Flow, type FlowNodeInput, type FlowTypes } from "@fragiola/flow-react";
import { connection } from "@fragiola/flow-react/connection";
import { drag } from "@fragiola/flow-react/drag";
import { selection } from "@fragiola/flow-react/selection";

interface Types extends FlowTypes {
    readonly nodes: { step: { label: string } };
}

const features = [selection(), drag(), connection()] as const;

const nodes: FlowNodeInput<Types>[] = [
    { id: "fetch", type: "step", position: { x: 0, y: 0 }, data: { label: "Fetch" } },
    { id: "save", type: "step", position: { x: 0, y: 140 }, data: { label: "Save" } },
];

export function Pipeline() {
    return (
        <Flow.Root<Types, typeof features>
            features={features}
            defaultNodes={nodes}
            defaultEdges={[{ id: "fetch-save", source: "fetch", target: "save" }]}
            fitView
            className="h-96"
        >
            <Flow.Viewport>
                <Flow.Edges<Types>>
                    {(edge) => <Flow.Edge<Types> edge={edge} className="stroke-gray-400" />}
                </Flow.Edges>
                <Flow.Nodes<Types>>
                    {(node) => (
                        <Flow.Node<Types> node={node} className="rounded border bg-white px-3 py-2">
                            {node.data.label}
                            <Flow.Handle type="target" side="top" className="size-2 rounded-full bg-gray-500" />
                            <Flow.Handle type="source" side="bottom" className="size-2 rounded-full bg-gray-500" />
                        </Flow.Node>
                    )}
                </Flow.Nodes>
                <Flow.ConnectionLine className="stroke-gray-400" />
            </Flow.Viewport>
        </Flow.Root>
    );
}
```

```vue title="pipeline.vue"
<script setup lang="ts">
import { type FlowNodeInput, type FlowTypes, typedFlow } from "@fragiola/flow-vue";
import { connection } from "@fragiola/flow-vue/connection";
import { drag } from "@fragiola/flow-vue/drag";
import { selection } from "@fragiola/flow-vue/selection";

interface Types extends FlowTypes {
    readonly nodes: { step: { label: string } };
}

const features = [selection(), drag(), connection()] as const;
const Flow = typedFlow<Types, typeof features>();

const nodes: FlowNodeInput<Types>[] = [
    { id: "fetch", type: "step", position: { x: 0, y: 0 }, data: { label: "Fetch" } },
    { id: "save", type: "step", position: { x: 0, y: 140 }, data: { label: "Save" } },
];
</script>

<template>
    <Flow.Root
        :features="features"
        :default-nodes="nodes"
        :default-edges="[{ id: 'fetch-save', source: 'fetch', target: 'save' }]"
        fit-view
        class="h-96"
    >
        <Flow.Viewport>
            <Flow.Edges v-slot="{ edge }">
                <Flow.Edge :edge="edge" class="stroke-gray-400" />
            </Flow.Edges>
            <Flow.Nodes v-slot="{ node }">
                <Flow.Node :node="node" class="rounded border bg-white px-3 py-2">
                    {{ node.data.label }}
                    <Flow.Handle type="target" side="top" class="size-2 rounded-full bg-gray-500" />
                    <Flow.Handle type="source" side="bottom" class="size-2 rounded-full bg-gray-500" />
                </Flow.Node>
            </Flow.Nodes>
            <Flow.ConnectionLine class="stroke-gray-400" />
        </Flow.Viewport>
    </Flow.Root>
</template>
```
